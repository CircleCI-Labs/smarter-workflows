# The sidebar of the docs site: its order, its groups and the labels of its pages (CONTRIBUTING.md, "Documentation site").
#
#   == Group title | Group lead (optional) | Source directory (optional)   starts a sidebar group. The lead becomes the group index
#                                           description. A link to the source directory (docs/adr/) goes to the group index.
#   ==                                      ends the group: the pages below it are top-level pages again.
#   path | Sidebar label | Description (optional) | Slug (optional)   a page. The description is used when the page has no
#                                           page-description. The slug is the last part of its address (default: its file name
#                                           without .md): two README.md files, or SKILL.md, need one.
#
# stage.sh fails on a Markdown file below docs/ that is not listed here, and on a listed file that does not exist, so a new,
# renamed or removed page always shows up in this file. STAGE_LENIENT=1 turns both errors into warnings.
# The landing page (README.md) is not listed: it is the home page of the site.
